# 07. Settings

Opened with right-click the dock → **Settings** [S: guides/liquid-glass-windows]. It's "laid out like the Mac's System Settings" [S: changelog 1.0.0], with info tips on every dock setting [S: changelog 1.2.13], and a red dot marks new items [S: changelog 1.2.6].

**No screenshot of Settings is published.** The sections below are rebuilt from every setting named on the site. Layout and section order are Gap G-01.
